# BettingRoyale MVP 브라우저 목업

「BettingRoyale MVP 기획」 문서를 그대로 구현한 웹 목업입니다. 준비 시간에 **도박·장비·강화·보유** 중 재화 배분을 결정하고, 자기장이 좁혀오는 전장에서 **누적 전투 점수**로 최종 승자를 가립니다. 남은 재화는 **이월 한도 안에서** 다음 라운드 투자 재원으로 이어집니다. Node.js 표준 라이브러리만 쓰고 의존성이 없습니다.

> 한 줄 소개: 돈을 쓰면 강해지고, 남기면 다음 라운드로 이월된다.

## 실행

```powershell
npm start
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다. `PORT` 환경 변수로 포트를 변경할 수 있습니다. 공개 검수 후보는 같은 PC에서 접속하는 로컬 데모입니다.

## 검증

```powershell
npm test                # 전체. 의존성 없이 node 만으로 실행됩니다.

npm run test:roulette   # 배당표·칸 배치·정산 · 개인 베팅 비공개 · 마감/환불

npm run test:stations   # 모루 확률 강화(선차감·실패 유지) · 장신구 뽑기 · 허수아비
npm run test:storm      # 자기장 수축·수렴점·밖 피해 · 보급 투하와 회수

```

## 방 만들기와 참가

- **공개방** — 방 목록에 노출됩니다. 목록에는 방 이름·현재/최대 인원·대전 모드·진행 단계가 표시됩니다.
- **비공개방** — 목록에 노출되지 않습니다. 친구에게 받은 **방 코드(6자리)** 로 검색한 뒤 **비밀번호**를 입력해 입장합니다.
- 방 생성자가 호스트가 되고, 호스트만 설정 변경과 게임 시작을 할 수 있습니다. 호스트가 나가면 남은 인간 플레이어에게 넘어갑니다.
- 진행 중 입장하면 관전하다가 다음 준비 단계부터 참가합니다. 연결이 끊기면 8초의 재접속 유예 후 이탈 처리됩니다.

## 봇과 참가 인원

- 참가 인원은 **인간·봇 합산 2–8명**입니다. 인간 1명이어도 봇을 채워 PvP 매치를 시작할 수 있습니다.
- 봇은 별도 PvE 규칙 없이 **인간과 동일한 규칙**(기본 재화·이월, 룰렛, 강화, 뽑기, 전투, 자기장, 점수)을 적용받습니다.
- 방이 가득 찼을 때 인간이 입장하면 로비의 봇이 자리를 양보합니다.

## 한 라운드의 구조

1. **준비 (기본 90초)** — 전원이 광장에 모입니다. 룰렛에 베팅하고, 상점에서 장신구를 뽑고, 모루에서 무기·방어구를 확률 강화하고, 서로 구걸하고 적선합니다. **전원이 준비 완료를 누르면 조기 종료**됩니다.
2. **전장 이동 (3초)** — 이때 **황금 고블린**(전투력이 가장 높은 플레이어)이 발표됩니다.
3. **전투 (기본 90초)** — 자기장이 좁혀오고 보급이 떨어지는 전장에서 싸웁니다. 개인전은 최후의 1인, 팀전은 최후의 1팀이 남으면 조기 종료됩니다.
4. **정산 (10초)** — 등수·킬·어시스트를 점수로 환산하고, 이월 한도를 적용합니다.
5. 설정한 라운드 수만큼 반복한 뒤 **누적 전투 점수**로 최종 순위를 냅니다.

| 항목 | 범위 | 기본값 |
| --- | --- | --- |
| 대전 모드 | 개인전 / 팀전 | 개인전 |
| 라운드 수 | 1 ~ 5 | 3 |
| 준비 시간 | 30 ~ 300초 | 90초 |
| 전투 시간 | 30 ~ 300초 | 90초 |
| 라운드 기본 재화 | 200 ~ 5,000 | 1,000 S |
| 최대 이월 한도 | 0 ~ 10,000 | 2,500 S |
| 보급 주기 | 5 ~ 60초 | 15초 |
| 봇 인원 | 0 ~ 7 | 1 |
| 팀 인원 (팀전) | 2 ~ 4 | 2 |
| 강화 이월 | 켜기 / 끄기 | **끄기** (문서 기본값) |
| 아군 공격 (팀전) | 켜기 / 끄기 | 끄기 (미결정 사항) |

## 재화와 이월

- 매 라운드 시작 시 모든 플레이어에게 **동일한 기본 재화 1,000S**를 지급합니다.
- 라운드 정산 시 **준비 라운드 종료 잔액 + 전투 라운드 획득 재화**를 합산하고 **최대 이월 한도**를 적용합니다.
  - `다음 라운드 이월 = min(준비 잔액 + 전투 획득, 이월 한도)` — 초과분은 소멸하며 정산 화면에 표시됩니다.
  - `다음 라운드 사용 가능 재화 = 기본 재화 + 이월 재화`
- **보유 재화는 점수에 포함되지 않습니다.** 이월 한도는 점수가 아니라 경제적 선택의 범위를 조절하는 장치입니다.
- 획득처: 라운드 기본 재화 · 킬(150S) · 어시스트(50S) · 생존 시간(최대 250S) · 등수 보상 · 바닥 보급 · 룰렛 당첨 · 적선 · 황금 고블린 현상금.

## 조작

- 이동: WASD · 조준: 마우스 · 공격: 좌클릭 · 대시: Space
- **상호작용: E** — 룰렛·상점·모루·순위판 근처에서 누르면 창이 열립니다.
- **적선: F** — 다른 플레이어 근처(46 이내)에서 누르면 적선 창이 열립니다.
- **구걸: Q** — 광장 전체에 알림이 뜨고 머리 위에 말풍선이 붙습니다.
- **전투 현황: Tab (전투 중)** — 강화 단계·생존 여부·킬/어시·생존자 수. 전투가 시작되면 장비는 공개 정보입니다.

키 입력은 물리 키 위치(`e.code`)로 처리하므로 한글 입력 상태에서도 동작합니다.

## 도박 — 룰렛 (러스트 방식)

광장의 룰렛이 **10초 베팅 → 10초 회전**을 반복합니다. `1 · 3 · 5 · 10 · 20` 중 한 곳에 걸고, 맞으면 **베팅액 × (숫자+1)** 을 회수합니다. 바퀴는 46칸이고 칸 배치가 곧 확률입니다.

| 숫자 | 칸 수 | 확률 | 총 회수 | 기대 회수율 |
| --- | --- | --- | --- | --- |
| 1 | 22 | 47.83% | ×2 | 95.7% |
| 3 | 11 | 23.91% | ×4 | 95.7% |
| 5 | 7 | 15.22% | ×6 | 91.3% |
| 10 | 4 | 8.70% | ×11 | 95.7% |
| 20 | 2 | 4.35% | ×21 | 91.3% |

- 어떤 칸도 기대 회수율 100%를 넘지 않으므로 필승 전략은 없습니다. 서버가 시작할 때 표와 배치의 일치를 검사합니다.
- **개인별 베팅은 비공개**이고 전체 판돈과 참여 인원만 공개됩니다.
- **준비 종료 20초 전에 마감**됩니다. 돌지 않은 베팅은 전액 환불되고, 이미 도는 판은 끝까지 정산합니다. 마감은 결과를 기다리는 룰렛에만 적용되며, **강화·뽑기는 준비 시간이 끝날 때까지 사용할 수 있습니다.**

## 장비 — 기본 지급 + 모루 확률 강화 + 장신구 뽑기

| 슬롯 | 핵심 효과 | 획득 |
| --- | --- | --- |
| 무기 | 피해량 · 사거리 · 공격 주기 | 기본 1종 지급 · **모루 확률 강화만** (구매 없음) |
| 방어구 | 최대 체력 · 이동 속도 | 기본 지급 · **모루 확률 강화만** (구매 없음) |
| 장신구 | 대시 횟수 · 대시 쿨타임 | **상점 랜덤 뽑기** (단독 슬롯 1개) |

### 모루 (확률 강화)

- 강화는 **확률형 투자**입니다. 재화를 **먼저 차감**하고, 실패하면 재화만 소모되고 단계는 오르지 않습니다.
- 슬롯별 +1 ~ +5. 성공 확률은 90% → 75% → 60% → 45% → 30%로 낮아지고 비용은 단계마다 올라갑니다. 확률과 비용은 UI에 그대로 표시됩니다.
- 강화 상태는 **기본적으로 라운드 간 이월되지 않으며**, 호스트 설정으로 켤 수 있습니다.
- 준비 라운드에는 강화 상태가 비공개이고, **전투가 시작되면 전원에게 공개**됩니다 (자연스러운 견제 유도).

### 상점 (장신구 뽑기)

- 뽑기 1회 400S. **일반(60%) · 희귀(30%) · 영웅(10%)** 등급과 3가지 종류(대시 횟수 / 대시 쿨타임 / 두 효과 조합)가 나옵니다. 전체 확률표가 공개됩니다.
- 뽑으면 **선택·보류 없이 즉시 장착**되고, 이미 장착 중이면 **무조건 교체**됩니다 — 뽑기 자체가 장비 교체 리스크입니다.

### 허수아비

광장의 얇은 허수아비를 때리면 현재 피해·사거리·공격 주기를 확인할 수 있습니다. 맞으면 흔들리는 모습이 전원에게 보입니다.

## 황금 고블린 (현상금)

전투 단계 시작 전, **전투력(장비·소모품 가격 합)이 가장 높은 플레이어**를 황금 고블린으로 지정합니다. 처치 시 500S, 어시스트 시 200S의 추가 재화가 걸립니다. 왕관 표시로 전원에게 공개되어 강자 견제를 유도합니다. 아무도 장비에 투자하지 않은 라운드에는 지정되지 않습니다.

## 전장

- 사각 경계 기반 전장 1개. 중앙 십자 구조물, 좌우 사이드 통로, 상자 12개(4개는 얇은 바리케이드)로 이동 경로와 시야를 나눕니다.
- **단일 평면**입니다. 고저차는 이동·공격·시야 판정에 없습니다. 점프·수직 이동도 없습니다.
- **낙사 구덩이 4개** — 이동을 막지 않지만 밟으면 떨어져 즉사합니다. 낙사는 킬을 주지 않습니다.
- 벽과 상자는 이동·대시·시야를 모두 막습니다. 사이에 지형이 있으면 사거리 안이라도 공격이 닿지 않습니다.
- 스폰 위치는 **매 전투 라운드 무작위**입니다. 벽·구덩이 밖에서, 서로 최소 거리(기본 130)를 지켜 뽑으므로 스폰 직후 즉시 공격받지 않습니다.
- 대시는 충전 횟수를 소모하고 250ms 무적을 제공합니다. 대시로 벽을 통과할 수 없습니다.
- **시야 제한(전장 안개)** — 본 화면도 미니맵과 같은 가시영역을 따릅니다. 벽에 가린 곳은 어둡게 덮이고, 그 안의 적·보급은 그려지지 않습니다. 나와 팀원은 항상 보이며, 죽어서 유령이 되면 시야 제한이 풀립니다.
- **죽으면 유령이 됩니다** — 라운드가 끝날 때까지 전장을 자유롭게 돌아다닐 수 있고(벽·구덩이 통과), 살아있는 유저에게는 보이지 않습니다. 죽은 유저·관전자끼리는 서로 유령이 보입니다. 공격·보급 회수는 불가능합니다.
- 공격은 조준 방향 ±0.85 라디안 안에서만 맞습니다.

## 자기장과 보급

- 전투 시간의 **20% 지점에 수축을 시작해 100% 지점에 최소 반경(40)으로 수렴**합니다. 수렴 중심은 전장 중앙 구역(3×3의 가운데 칸) 안에서 매 라운드 무작위입니다.
- 안전 구역 밖에서는 **초당 12 피해**를 받습니다. 자기장 사망은 킬을 주지 않지만, **10초 안에 피해를 준 플레이어에게는 어시스트**가 갑니다.
- 보급은 주기(기본 15초)마다 **안전 구역 안, 벽 밖**에만 떨어집니다. 종류는 **재화 상자(60%)와 힐팩(40%)** 두 가지이고, 힐팩은 **최대 체력 비례(35%)** 로 회복합니다. 밟으면 자동 회수됩니다.

## 점수와 최종 승리

**라운드 점수 = 등수 점수 + 킬 점수 + 어시스트 점수**

| 항목 | 점수 | 재화 |
| --- | --- | --- |
| 등수 | 1위 25점 ~ 최하위 10점 | 1위 600S ~ 최하위 300S |
| 킬 | 3점 | 150S |
| 어시스트 | 1점 | 50S |
| 생존 시간 | — (점수 없음) | 최대 250S |

- **최종 점수 = 누적 라운드 전투 점수.** 보유 재화는 점수에 포함하지 않고 최종 화면에 별도 자산 지표로 표시합니다.
- 라운드 등수는 생존 > 늦게 죽음 > 킬 > 어시스트 > 잔존 체력 순으로 정합니다.
- **동점 판정**: ① 총 점수 → ② 전투력(장비·소모품 가격 합) → ③ 서버 난수. 난수까지 간 동점은 **2인이면 동전 뒤집기, 다인이면 룰렛 추첨 연출**로 표시합니다 (시각적 표현이며 실제 위험 행위와 무관합니다).

## 팀전

- 2v2 · 3v3 · 4v4. 팀은 승리 목표와 전투 협력 단위일 뿐, **공용 자금은 없습니다.**
- 재화·장비·강화·적선 기록은 모두 개인 소유이고, 재화 이전은 **적선으로만** 가능합니다.
- 아군 공격은 기본 꺼짐 (문서상 미결정 사항 — 호스트 설정으로 켤 수 있음).
- 팀 라운드 승패는 최후의 1팀 → 생존 인원 → 킬 합계로 정합니다. **팀 승패와 개인 누적 점수의 결합 방식은 문서상 미결정 사항**이라 최종 화면에 둘을 따로 보여줍니다.

## 적선과 구걸

- **구걸 (Q)** — 광장 전체에 알림이 뜨고 머리 위에 말풍선이 붙습니다. 4초 쿨다운.
- **적선 (F)** — 상대에게서 46 이내로 걸어가야 합니다. 최소 10S, 잔액 초과는 전액으로 잘립니다.
- 준비 중 남의 지갑은 감춰지지만, **누가 누구에게 얼마를 줬는지와 누적 적선/수령액은 전원에게 공개**됩니다. 재화 총량은 보존됩니다 — 적선은 만들지 않고 옮깁니다.

## 규칙의 단일 출처와 서버 권한

- 확률표·강화 비용·장신구 확률·지형·설정 범위는 모두 `server.js` 한 곳에 정의되고 `GET /config`로 그대로 공개됩니다. 클라이언트는 이 응답을 렌더링만 합니다.
- 페이즈·타이머·룰렛 추첨·강화 판정·뽑기·전투·사망·순위·동점 판정·이월 계산: **서버**.
- 좌표는 클라이언트가 예측해 보내고 서버가 속도·충돌·낙사를 검증합니다.
- 상점·모루·룰렛·적선은 서버가 거리를 확인합니다.

## 알려진 제약 (목업 전제)

- `/action`은 요청 본문의 `id`를 그대로 신뢰합니다. 내부망 목업 전제라 인증이 없습니다.
- 새로고침하면 재접속 복구가 없어 새 플레이어로 참가합니다.
- PC 전용입니다 (터치 조작 없음). 문서의 3D·쿼터뷰는 2D 캔버스의 가짜 원근으로 대체했습니다.
- 컨트롤러(Xbox) 입력은 목업에 포함하지 않았습니다.
