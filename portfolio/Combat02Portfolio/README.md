# BettingRoyale · Combat 02 Graybox

원본 전장의 구역, 주요 이동 경로와 충돌 구조를 기반으로 재구성한 포트폴리오용 Unity 씬입니다. 기본 큐브로 바닥·벽 충돌을 시각화하고, 원본의 배치 좌표와 중앙·스폰·상자 표식을 남겼습니다.

## 기여

cutenabi0527은 전장 기획, 다섯 구역과 동선 설계, Unity 씬 제작·오브젝트 배치, 환경 구성, Blender 및 AI 보조 도구를 활용한 에셋 생성·검토를 주도했습니다. 일부 디버깅과 최적화는 팀원과 함께 진행했습니다.

## Unity에서 열기

Unity Hub에서 이 폴더를 프로젝트로 추가하고 Unity `6000.3.22f1`로 열어 [전장 씬](Assets/Scenes/Map_Combat_02_Portfolio.unity)을 선택합니다. 씬에는 전체 배치를 살펴볼 수 있는 카메라와 미리보기용 조명이 있습니다. 독립 프로젝트의 패키지 선언에는 Unity 내장 Physics 모듈만 있습니다.

## 원본과 대조한 범위

| 항목 | 원본과의 비교 |
| --- | --- |
| 구역 | 중앙·북서·북동·남서·남동의 계층을 보존했습니다. 배치 위치 41곳을 표식으로 복원했습니다. |
| 충돌 | 전체 1,174개, 활성 348개입니다. 보존한 Collider의 월드 위치·회전·크기 불일치 0건입니다. |
| 표식 | 중앙 `(0, 0.04, 0)`, 스폰 8곳, 상자 앵커 8곳의 월드 좌표가 일치했습니다. |
| 씬 참조 | 외부 GUID와 끊긴 로컬 파일 참조가 각각 0건입니다. |

플레이어 이동, 상자 생성, 전투, 네트워크와 안개 로직은 이 씬의 범위에서 제외했습니다. 배치 표식은 원본 모델 대신 위치를 표시합니다.

## 프로젝트에서 제작한 모델과 Editor 도구

| 파일 | 제작 및 검증 범위 |
| --- | --- |
| [성곽 내벽 모듈](Assets/Models/SM_Fortress_InnerWallModule.fbx) | Blender에서 생성한 벽 메시입니다. 제작 과정에 AI 보조가 사용됐습니다. 생성기 재실행 결과와 원본 FBX의 정점, 면 방향 및 면별 UV를 대조했습니다. |
| [RoyalPier](Assets/Models/RoyalPier.fbx) | 준비 구역용으로 Blender에서 절차적으로 제작한 기둥입니다. 생성기 재실행 결과와 원본 FBX의 면 구조와 정점 좌표를 대조했습니다. |
| [AlignMapCenter](Assets/Editor/AlignMapCenter.cs) | 원본 맵 작업에서 렌더러 경계를 기준으로 루트를 중앙 마커에 X/Z 방향으로 정렬한 Unity Editor 도구입니다. 파일별 최초 작성과 AI 보조 여부는 확인 범위에 따라 개별 표기를 유보했습니다. |

두 FBX는 Graybox 씬과 독립적으로 살펴볼 수 있습니다. RoyalPier의 Blender 작업경로는 공개본 메타데이터에서 제거했습니다. FBX 안의 머티리얼 슬롯과 색상은 유지했습니다. 외부 모델·텍스처와 상용 SDK 원본은 제공 범위에서 제외했습니다. 프로젝트 전체 의존성은 [외부 구성요소 고지](../../THIRD-PARTY-NOTICES.md)를 참고하세요.

**검증**　씬 YAML과 원본 좌표의 정적 검사는 통과했습니다. Blender에서 두 FBX 원본을 열고 모델 생성 코드를 재실행해 메시를 대조했습니다. Unity Editor는 라이선스 오류로 씬을 로드하기 전에 중단됐습니다. FBX Unity 임포트, Editor 도구 컴파일, Play 모드와 빌드는 검증하지 못했습니다.
